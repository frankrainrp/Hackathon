Butler's existing Latin font assets, bundled for reproducible offline builds.

Inter: variable weight 100-900; The Inter Project Authors.
Cinzel: variable weight 400-900; The Cinzel Project Authors.
Both are distributed under SIL Open Font License 1.1; see the accompanying licenses.
Font bytes are the unmodified WOFF2 files previously emitted by this app's Google Fonts build.
The existing system-font fallbacks continue to supply Chinese and other glyphs.
